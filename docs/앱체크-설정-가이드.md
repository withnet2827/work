# 앱 체크(App Check) 설정 가이드 — reCAPTCHA v3 (무료)

목적: AI 사진 분석 같은 서버 기능을 **치오 데일리 사이트에서 온 요청에만** 허용합니다.
코드는 이미 준비돼 있고, 아래 1~3단계에서 만든 **사이트 키**를 `app/lib/firebase_config.dart`의 `recaptchaSiteKey`에 넣으면 켜집니다.

> 순서가 중요합니다. **키를 넣고 배포해 앱이 토큰을 보내는 것을 확인한 뒤에** 4단계(적용)를 하세요.
> 먼저 적용하면 모든 AI 요청이 막힙니다. 막히면 적용을 해제하면 바로 풀립니다.

## 1. reCAPTCHA v3 키 만들기
1. https://www.google.com/recaptcha/admin/create 접속(구글 로그인).
2. 라벨: `chio-daily`, 유형: **점수 기반(v3)**.
3. 도메인에 아래 세 개를 추가합니다.
   - `chio-daily.web.app`
   - `chio-daily.firebaseapp.com`
   - `localhost` (PC에서 테스트할 때만)
4. 제출하면 **사이트 키**(공개)와 **비밀 키**가 나옵니다. 비밀 키는 다음 단계에서만 씁니다. 코드에는 넣지 않습니다.

## 2. 파이어베이스에 등록
1. Firebase 콘솔 → 빌드 → **App Check** → 앱 `chio-web` → **reCAPTCHA** 선택.
2. 위에서 받은 **비밀 키**를 붙여 넣고 저장합니다.

## 3. 앱에 사이트 키 넣고 배포
1. `app/lib/firebase_config.dart`에서 `recaptchaSiteKey = ''`의 따옴표 안에 **사이트 키**를 붙여 넣습니다.
2. 저장 후 평소처럼 빌드·배포합니다(`flutter pub get` 포함).

## 4. 적용(Enforce) — 배포 후 확인한 다음
1. 앱 체크 화면의 **요청 지표(Metrics)**에서 "확인된 요청"이 올라오는지 봅니다. AI 분석을 몇 번 눌러 보세요.
2. 확인되면 **API** 탭에서 `Firebase AI Logic`(또는 Generative Language API)을 **적용(Enforce)**으로 바꿉니다.
3. 앱에서 **AI로 사진 분석**이 되는지 다시 확인합니다. 실패하면 적용을 해제하세요.

## 참고
- 사이트 키는 공개 값이라 코드에 들어가도 됩니다.
- 로컬(`localhost`)에서 테스트하려면 1단계에 `localhost`를 추가했는지 확인하세요.
