# Firebase 설정 가이드 (구글 로그인 + 가족 공유)

소요 시간 약 15분. 모두 **무료(Spark 요금제)** 로 진행하며 카드 등록이 필요 없습니다.
용어: 콘솔 = https://console.firebase.google.com

## 1단계. 프로젝트 만들기
1. 콘솔 접속(구글 계정 로그인) → **프로젝트 추가**
2. 이름: `chio-daily` (아무 이름 가능) → 계속
3. Google 애널리틱스: **사용 안 함** → 프로젝트 만들기

## 2단계. 웹 앱 등록
1. 프로젝트 첫 화면에서 `</>`(웹) 아이콘 클릭
2. 앱 닉네임: `chio-web` → **Firebase Hosting 설정은 체크하지 않음**(나중에 안내) → 앱 등록
3. 화면에 `firebaseConfig = { apiKey: "...", authDomain: "...", projectId: "...", storageBucket: "...", messagingSenderId: "...", appId: "..." }` 가 나옵니다.
4. 이 6개 값을 **저에게 그대로 붙여 넣어 주세요.** (웹 설정값은 공개 식별자라 공유해도 안전합니다. 보호는 아래 보안 규칙이 담당합니다.)

## 3단계. 구글 로그인 켜기
1. 왼쪽 메뉴 **빌드 → Authentication → 시작하기**
2. **로그인 방법** 탭 → **Google** → 사용 설정 ON
3. 프로젝트 지원 이메일: 본인 Gmail 선택 → 저장

## 4단계. Firestore 데이터베이스 만들기
1. **빌드 → Firestore Database → 데이터베이스 만들기**
2. 위치: `asia-northeast3 (서울)` → **프로덕션 모드**로 시작 → 만들기
3. **규칙** 탭 → 저장소의 `firestore.rules` 파일 내용을 전부 복사해 붙여 넣기 → **게시**

## 5단계. 허용 도메인 확인
- Authentication → 설정 → **승인된 도메인**에 `localhost`가 있어야 합니다(기본 포함).
- 앱을 인터넷에 올린 뒤(다음 단계, Firebase Hosting)에는 그 주소가 자동 추가됩니다.

## 결과 확인
값을 받으면 제가 `app/lib/firebase_config.dart`에 입력합니다. 이후 아래로 실행하면 구글 로그인 화면이 나옵니다.

```powershell
cd C:\dev\work\app
git pull
flutter pub get
flutter run -d chrome --web-port 8080
```

> 처음 로그인한 사람은 **새 가족 만들기**, 다른 가족은 로그인 후 **초대 코드 입력**으로 참여합니다. 초대 코드는 앱 상단 가족 아이콘에서 볼 수 있습니다.

## 다음: 가족이 접속할 주소 만들기 (Firebase Hosting)
가족 3명이 접속하려면 앱이 인터넷에 올라가 있어야 합니다. (`localhost`는 내 PC에서만 열립니다.) Node.js 설치와 `firebase deploy` 몇 줄이면 되고, 그때 단계별로 안내합니다. 안드로이드·아이폰 모두 크롬/사파리에서 열고 **홈 화면에 추가**하면 앱처럼 쓸 수 있습니다.

## 알아둘 점
- 같은 항목을 두 명이 동시에 수정하면 **나중에 저장한 쪽이 이깁니다.** 다른 가족의 변경은 상단 새로고침(↻)으로 불러옵니다. (실시간 자동 반영은 다음 개선 항목)
- 사진은 압축해 Firestore에 저장합니다. 무료 저장 1GB로 수천 장 가능합니다. 구글 드라이브 백업은 이후 단계에서 추가합니다.
