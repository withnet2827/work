# 배포 가이드 (Firebase Hosting)

앱을 인터넷에 올려 가족이 주소 하나로 접속하게 합니다. 무료(Spark)로 가능합니다.
배포 주소: `https://chio-daily.web.app` (또는 `https://chio-daily.firebaseapp.com`)

## 최초 1회: 도구 설치
1. **Node.js LTS** 설치: https://nodejs.org (설치 후 PowerShell을 새로 엽니다)
2. Firebase 도구 설치:
   ```powershell
   npm install -g firebase-tools
   ```
3. 로그인(브라우저가 열리면 Firebase 프로젝트를 만든 구글 계정으로):
   ```powershell
   firebase login
   ```

## 배포 (코드가 바뀔 때마다)
```powershell
cd C:\dev\work
git pull
cd app
flutter pub get
flutter build web --release
cd ..
firebase deploy --only hosting
```
끝나면 `Hosting URL: https://chio-daily.web.app`이 표시됩니다.

> ⚠ **배포 전에 반드시 빌드를 다시 하세요.** `firebase deploy`는 `app/build/web`에 이미 만들어진 파일을 올립니다.
> `git pull`만 하고 빌드를 건너뛰면 예전 화면이 그대로 배포됩니다. (`firebase deploy` 맨 앞에 `found N files in app/build/web`이 보입니다.)
> 배포 후 화면이 안 바뀌면 `Ctrl+F5`, 그래도 안 바뀌면 시크릿 창으로 열어 캐시 문제인지 확인하세요.

## 로그인 도메인 허용 확인
Firebase 콘솔 → Authentication → **설정** → **승인된 도메인**에 `chio-daily.web.app`이 있는지 확인합니다(보통 자동 추가). 없으면 **도메인 추가**로 입력하세요.

## 가족 폰에 설치(홈 화면에 추가)
- **안드로이드(크롬)**: 주소 접속 → 오른쪽 위 ⋮ → **홈 화면에 추가** (또는 **앱 설치**)
- **아이폰(사파리)**: 주소 접속 → 공유 버튼(□↑) → **홈 화면에 추가**
  - 아이폰은 반드시 **사파리**로 열어야 홈 화면 추가가 됩니다.
- 홈 화면의 '치오' 아이콘을 누르면 앱처럼 전체 화면으로 열립니다.
- 첫 사용: 구글 로그인 → (처음 사람) 새 가족 만들기 / (나머지) 초대 코드 입력.

## 문제 해결
- **업데이트가 안 보임**: 앱을 완전히 닫았다가 다시 열거나 새로고침. 홈 화면 앱은 두 번 열어야 새 버전이 적용될 수 있습니다.
- **로그인 팝업이 막힘**: 브라우저의 팝업 차단을 해제합니다. 인앱 브라우저(카카오톡 등)로 열면 로그인이 안 될 수 있으니 크롬/사파리에서 직접 여세요.
